# Tableau de bord du pipeline NIDS

Copier le dossier `dashboard/` à la racine du projet (à côté de `src/`, `scripts/`, `data/`, `reports/`). Aucune dépendance nouvelle.

Lancement, depuis la racine du projet :

    python -m dashboard.server

puis ouvrir http://127.0.0.1:8765 (options : --port, --root, --no-browser).
